## 🚨 現場での初動 5大ステップ

```
[STEP 1] ケガ人の救護・安全確保（最優先）
   ↓
[STEP 2] 警察への通報（110番） ★自損事故でも絶対に届出！
   ↓
[STEP 3] KidsRide本部（緊急窓口）へ電話一報
   ↓
[STEP 4] 相手方情報の確認 & スマホで現場写真の撮影
   ↓
[STEP 5] アプリから「事故報告フォーム」を送信
```

---

### STEP 1: 負傷者の救護・安全確保（最優先）
* ハザードを点灯し、安全な場所へ車両を停車。
* 乗車中のお子様および相手方の負傷の有無を確認。
* 負傷者がいる場合は、直ちに **119番（救急車）** を手配してください。

### STEP 2: 警察への通報（110番） ★最重要
* **相手がいない単独事故（自損事故）でも、必ず警察を呼んで事故処理を行ってください。**
  * ※警察への届出がないと「交通事故証明書」が発行されず、送迎中の事故であることの客観的証明や保険適用が受けられなくなります。
* 警察官が到着したら、指示に従って状況を説明してください。
* **【安心ポイント】担当警察官の名前や事故番号がその場で分からなくても大丈夫です！**
  * 警察への110番通報さえ完了していれば、発生場所から保険会社側で管轄警察署を特定して事故受付が可能です。分かった範囲（署名など）だけ控えておけば問題ありません。

### STEP 3: KidsRide本部（緊急連絡先）へ電話一報
* 本部にて保護者様への状況説明・代行送迎手配・保険会社連携を直ちに行います。
* **KidsRide 緊急ホットライン**: `070-2251-1896` （担当: 七夕）
* **【重要規則】登録ドライバーが直接あいおいニッセイ同和損保へ事故報告することは禁止されています。事故報告・保険請求窓口はすべてKidsRide本部が行います。**

### STEP 4: 相手方情報の確認 ＆ 現場写真の記録
#### ① 相手方がいる場合の情報確認
* 相手の氏名、電話番号、住所
* 相手車両のナンバープレート、車種・色
* 相手の加入任意保険会社名
* **【厳禁】その場での口約束・示談交渉（「全額弁償します」等）は絶対にしないでください。**
  * 「保険会社とKidsRide本部を通じて正式に対応いたします」とお伝えください。

#### ② スマホで現場を撮影（3〜5枚）
* 自車のキズ・凹み
* 相手車両のキズ・凹み
* 事故現場の全体風景（道路の幅、交差点、標識、信号機など）
* お互いの停止位置・タイヤの向き

### STEP 5: アプリから「事故報告フォーム」送信
* 現場の対応が完了し安全が確保されたら、KidsRideアプリの送迎者ダッシュボードより「事故報告」を入力・送信してください。
* **事故番号や相手の詳細が未定でも送信できます。** 警察への届出が済んでいればすぐに送信してください。

## 🛡️ 加入保険特約の重要ルール（必ずご確認ください）

当プラットフォームでは、あいおいニッセイ同和損保の**「移動支援サービス事業用自動車保険（優先補償・車両保険なし）特約」**を包括契約しています。

| 補償項目 | 補償内容 |
| :--- | :--- |
| **対人賠償** | **無制限**（対歩行者等傷害特約あり） |
| **対物賠償** | **無制限**（免責なし・対物超過修理費用特約50万円限度あり） |
| **人身傷害** | **1名につき 3,000万円**（同乗児童・ドライバーのケガを補償） |
| **ロードサービス** | レッカー運搬費用等（※代車補償対象外特約） |

### ⚠️ ドライバーの皆さまへの注意事項（免責事項）
1. **車両保険（自車の修理費）および代車費用は対象外です**
   * ドライバーご自身の車両修理費用や代車費用は本保険の対象外となります。登録車両が無保険車とならないよう、**ご自身での自動車保険（任意保険）の継続加入が必須**です。
2. **補償対象区間（合理的な経路の遵守）**
   * 移動支援サービスのために「自宅等を出発した時から自宅等へ帰着した時（待機を含む）」が補償対象です。
   * 私用や著しい遠回りなど、**通常の送迎過程を著しく逸脱した寄り道中の事故は補償対象外**となります。送迎終了後は速やかな帰宅をお願いいたします。
3. **事前登録された車両のみが補償対象**
   * 事前承認されていない車両での運行は一切補償されません。車両を変更する場合は必ず事前にKidsRideへご申請ください。
