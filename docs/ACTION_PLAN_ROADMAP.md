# KidsRide 今後のアクションプラン＆ロードマップ（時系列タスク集）

本計画は、事業計画書に基づき、**「①三鷹市への相談」「②園・保護者アンケート」「③実証実験の実施・検証」**の3つのステップを時系列で整理した総合実行計画です。

---

## 全体タイムライン概要（2026年10月〜2027年4月）

```
2026年10月中旬〜下旬
 ├── 【STEP 1】三鷹市への事前相談・連携体制の構築
 └── 【準備】アンケート（Googleフォーム/チラシ）準備 ＆ 保険契約の締結
      ↓
2026年10月下旬〜11月中旬
 └── 【STEP 2】保育園・幼稚園への訪問 ＆ 保護者向けアンケート調査の実施
      ↓
2026年11月中旬〜12月末（約2〜3か月）
 └── 【STEP 3】実証実験（1〜3施設・約30世帯・月100回）の開始・運用・検証
      ↓
2027年1月〜3月
 └── 実証結果の分析、本格版アップデート、三鷹市・地域公共交通会議への報告
      ↓
2027年4月〜
 └── 本格運用の開始（月額会費制導入・対象園の拡大）
```

---

## 【STEP 1】三鷹市への相談・関係構築（10月中旬〜10月下旬）

行政（三鷹市）との事前すり合わせを行い、既存事業との役割分担を明確にして「行政公認・共存」の土台を作ります。

| 時期 | タスク内容 | 具体的なアクション・確認事項 | 担当・成果物 |
| :--- | :--- | :--- | :--- |
| **10月中旬** | **相談窓口の特定・アポイント取得** | ・子ども政策部（子ども育成課 / 保育課）<br>・地域交通・都市交通担当課<br>※「民間立ち上げ前の事前相談と情報共有」としてアポ打診 | 代表理事 七夕 |
| **10月中旬〜下旬** | **市役所訪問・事業概要の説明** | ・東京運輸支局の書面回答（登録不要）を提示し、**違法性のない安心な互助設計**であることを説明<br>・**ファミサポとの共存方針**を説明（事前調整型のファミサポに対し、KidsRideは突発・日常送迎の互助）<br>・実証実験の対象園選定についての助言を依頼 | 相談資料一式<br>支局回答書写し |
| **10月下旬** | **三鷹商工会への補助金申請** | ・中小企業等産業活性化補助金（創業者特例・上限30万円）の申請手続き（アンケート・チラシ・Web広告費に充当） | 補助金申請書類 |

---

## 【STEP 2】園・保護者向けアンケート調査（10月下旬〜11月中旬）

園長先生へのアプローチを「調査協力」という低リスクな形で開始し、保護者の潜在ニーズを可視化するとともに実証実験の初期ユーザーを獲得します。

| 時期 | タスク内容 | 具体的なアクション・確認事項 | 担当・成果物 |
| :--- | :--- | :--- | :--- |
| **10月下旬** | **調査ツールの開設・資材準備** | ・Googleフォームの開設（設問票の登録、回答リンク・QRコード発行）<br>・A4案内チラシへのQRコード貼り付け・印刷（300〜500部）<br>・園長先生向け公式依頼状の印刷・準備 | `docs/PARENT_SURVEY_FORM.md`<br>`docs/SURVEY_FLYER_DRAFT.md`<br>`docs/KINDERGARTEN_REQUEST_LETTER.md` |
| **10月下旬〜11月上旬** | **対象園（1〜3施設）への訪問・依頼** | ・三鷹駅周辺の候補園（保育園・幼稚園）へ電話アポイント後、訪問<br>・依頼状とチラシ見本を持参し、「保護者の送迎実態調査」の協力依頼<br>・お便り袋への同封、または掲示板へのポスター掲示の承諾を取り付ける | 訪問・配布依頼 |
| **11月上旬〜中旬** | **アンケート実施・回答回収** | ・約2週間の回答受付（スマホでの回答がスプレッドシートに自動蓄積）<br>・回答の進捗確認（目標回答数：50〜100件程度） | Googleスプレッドシート |
| **11月中旬** | **集計レポートの作成・園へ共有** | ・Googleフォームの自動グラフをまとめ、**「保護者送迎実態レポート」**を作成<br>・園長先生へ持参して共有（*「送迎不安で第一希望を諦めかけた方が〇%」「急な残業時の送迎ニーズが〇%」等の数字を提示し、実証実験の協力へ繋げる*） | 集計レポート |

## 【STEP 3】実証実験の実施・検証（11月中旬〜12月末）

アンケートで集まったモニター希望者を中心に、安全運行と保険体制を完全稼働させた実証実験を行います。

| 時期 | タスク内容 | 具体的なアクション・確認事項 | 担当・成果物 |
| :--- | :--- | :--- | :--- |
| **11月上旬** | **団体保険の契約完了** | ・あいおいニッセイ同和損保との最終手続き<br>　① 自動車包括特約（申込書捺印、9台情報提出）<br>　② NPO活動総合保険（自転車・徒歩送迎用、暫定・確定精算方式での締結） | 保険証券・加入完了 |
| **11月中旬** | **モニター登録・事前審査** | ・アンケート回答者のうち「実証案内希望者」へ優先登録案内を送付<br>・参加保護者（約30世帯）および送迎サポーター（約15名）のアプリ登録<br>・サポーターの本人確認・在園確認・車検証・備付名簿登載の完了 | KidsRideアプリ・管理台帳 |
| **11月中旬** | **実証実験キックオフ（運行開始）** | ・実証実験の開始（送迎マッチング、GPS追跡、出庫前点検・アルコール記録）<br>・参加費用：実証期間中はシステム利用料無料（実費・ポイントのみ授受） | 実証実験運用開始 |
| **11月〜12月** | **月次運行・安全管理・保険通知** | ・日常の運行モニタリング（誤認引き渡し防止、GPSログ監視）<br>・事故・ヒヤリハットの即時受付（万一の際はKidsRide本部が損保窓口代行）<br>・12月10日：あいおい損保への11月度月次稼働実績通知（管理画面からCSV出力） | 月次実績報告CSV |
| **12月末** | **実証実験の終了・集計・評価** | ・目標KPIの検証（月100回運行、事故ゼロ、アンケート満足度80%以上）<br>・参加保護者・サポーターへの事後アンケート実施 | 実証実験総括レポート |

## その後の展開（2027年1月〜4月 本格運用へ）

* **2027年1月〜3月（本格運用準備・制度協議）**
  * 実証実験総括レポートを**三鷹市・地域公共交通会議・三鷹商工会**へ提出。
  * アプリ本格版アップデート、月額会費（500円）課金システムの接続。
  * 対象園を三鷹市内の3施設から順次拡大。
* **2027年4月（本格運用のスタート）**
  * 有料会員制（月額500円）による本格サービス開始。
  * 目標：導入6施設・登録120世帯（2027年7月目標）。
