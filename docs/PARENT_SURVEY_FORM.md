# 【三鷹市・子育て世帯対象】子どもの通園・送迎に関するアンケート調査

### ■ フォーム冒頭の案内文

```text
【所要時間：約2〜3分 / 無記名回答可】

皆様からいただいた生の声は、今後の地域サポート体制の設計や、三鷹市・関係機関への提案資料として大切に活用させていただきます。
率直なご意見・お困りごとをお聞かせいただけますと幸いです。

※本アンケートは統計的に処理され、個人の特定や営利目的の営業活動に使用されることは一切ございません。
```
