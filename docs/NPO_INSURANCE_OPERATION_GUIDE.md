# KidsRide 自転車・徒歩送迎向け保険運用ガイド（あいおいニッセイ同和損保「NPO活動総合保険」）

本書は、KidsRideにおける**自転車および徒歩による子ども送迎サポート**に適用する、あいおいニッセイ同和損害保険株式会社「**NPO（非営利活動団体）活動総合保険**」の補償内容、加入・契約運用、本番Webへの明記事項、および事故初動オペレーションを定めた公式ガイドラインです。

---

## 1. 保険の概要と適用根拠

KidsRideでは、送迎手段に応じて以下の**2系統の包括保険（ハイブリッド体制）**を整備します。

| 送迎手段 | 適用保険商品・特約 | 引受損保・取扱代理店 | 主な補償限度額 |
| :--- | :--- | :--- | :--- |
| **自動車送迎** | 移動支援サービス事業用自動車保険 包括特約 | あいおいニッセイ同和損保（保険あっとなびプラネット） | 対人・対物無制限、人身傷害3,000万円<br>（90円/h/日精算、車両保険なし） |
| **自転車・徒歩送迎** | **NPO活動総合保険**<br>（賠償責任特約＋団体傷害特約） | あいおいニッセイ同和損保（保険あっとなびプラネット） | **対人・対物最高2億円**（免責0円）<br>送迎者傷害：入院2,000円/日、通院1,000円/日 |

### 自転車・徒歩送迎に適用できる理由
- **施設所有（管理）者賠償責任保険**の約款上、「自動車または原動機付自転車（バイク）」に起因する事故は除外されますが、**「原動力が専ら人力である場合（＝自転車・電動アシスト自転車・徒歩）」は除外規定から除外され、補償の対象**となります。
- KidsRideの管理下（アプリでマッチングされ、送迎中・引率中）において、送迎サポーターが通行人や児童にケガをさせたり、他人の物を壊した場合の法律上の損害賠償責任が包括補償されます。

## 2. 補償内容の詳細一覧

### (1) 基本契約(a)：NPO賠償責任保険（第三者への賠償）
* **施設所有（管理）者賠償責任（対人・対物共通）**：**1事故・保険期間中 最高 2億円**（自己負担金/免責金額: 0円）
  * 例：自転車運転中に歩行者と接触して負傷させた、引率歩行中に児童が車道へ飛び出し他車と接触した等の賠償責任。
* **対人見舞費用補償（自動セット）**：
  * 法律上の過失・賠償責任が問われない場合でも、慣習として支払う見舞金をカバー。
  * 死亡：50万円 / 後遺障害：2万〜50万円 / 入院：2万〜10万円 / 通院治療：1万〜5万円
* **管理財物損壊補償**：**1事故 50万円**（預かり品・児童の持ち物・レンタル備品等の破損）
* **事故対応費用補償**：**1事故 500万円**（現場保存・写真撮影・初期対応・訴訟対応費用）
* **人格権侵害補償特約（自動セット）**：1名50万円 / 1事故100万円（プライバシー侵害・名誉毀損等の対応）

### (2) 基本契約(b)：NPO団体傷害保険（送迎サポーター自身のケガ）
送迎サポーター（会員・ボランティア）が送迎中、または**自宅と送迎場所との通常経路往復途上**に急激かつ偶然な外来の事故でケガを負った場合に補償されます。
* **死亡・後遺障害保険金額**：**200万円**
* **入院保険金日額**：**2,000円**（事故の日から180日以内、**1日目から対象**）
* **通院保険金日額**：**1,000円**（事故の日から180日以内、**1日目から対象**、ギプス固定期間を含む）
* **手術保険金**：入院中手術 20,000円（日額×10倍） / 外来手術 10,000円（日額×5倍）

## 3. 加入方法と運用の要件

### ① 準記名式（個別記名不要・名簿備え付け義務）
* 個々の送迎サポーターの氏名を保険会社へ事前に提出・登録する必要はありません。
* **要件**：KidsRide管理本部において、**「送迎構成員（会員・ボランティア）の最新名簿」を備え付けておくこと**が義務付けられています。
* **KidsRideシステム対応**：管理ポータル（`#admin`）の「事故・損保対応」タブに、**「【準記名式】備付名簿CSV出力 (NPO保険用)」**機能を実装済み。ワンクリックで最新の備付名簿（氏名・連絡先・住所・所属園・登録日）を出力・保管できます。
* 中途でサポーターが増減しても、その都度保険会社へ異動届を提出する必要はありません。

### ② 保険料の精算方式
* **暫定精算方式（原則）**：申込時に想定活動時間・延べ人数に基づき暫定保険料を納付し、契約満了時（1年後）に実態に基づき確定精算。
* **保険料確定方式（保険料確定特約）**：直近実績または初年度想定に基づき保険料を確定させ、満期時の精算手続きを省略する方式（平様への見積もり時に要相談）。

### ③ 告知事項
* 申込時に「団体の非営利活動内容（子どもの自転車・徒歩による通園・通学送迎支援）」を正確に告知します。

## 4. 本番Webサイト・アプリに明記すべき事項

本番Webサイト（LP、利用規約、FAQ、サポーター登録画面）には、以下のポイントを分かりやすく明記します。

### (1) 利用者（保護者）向け
1. **安心の二重補償体制**：
   * 車送迎だけでなく、**自転車・徒歩送迎中もあいおいニッセイ同和損保の「NPO活動総合保険」により最高2億円の対人・対物賠償責任保険が付帯**しています。
2. **見舞金・手荷物補償**：
   * 万一の事態には法律上の賠償責任の有無にかかわらず見舞金制度が適用され、お子様の手荷物・預かり品（ランドセル・水筒等）の破損にも対応します。

### (2) 送迎サポーター（会員・ボランティア）向け
1. **自動付帯＆個人負担ゼロ**：
   * KidsRideでサポーター審査が完了すると、自動的に「KidsRide会員名簿」に登載され、活動中の事故に対する補償が適用されます。個別の保険料負担や加入手続きは不要です。
2. **サポーター自身のケガも補償（往復途上含む）**：
   * 送迎中はもちろん、自宅から集合場所・送迎先への往復移動中の転倒や交通事故によるケガ（入院・通院・手術）も1日目から補償されます。
3. **安全基準の遵守**：
   * 自転車送迎時は、幼児同乗用シートの安全ベルト装着、お子様および運転者のヘルメット着用、日常点検を義務付けます。

### (3) 免責・注意事項（法的ガードレール）
1. **サービス提供外の私用移動は対象外**：
   * アプリ上で送迎依頼を受託し、運行中（GPS記録中）の活動のみが対象です。個人の私用運行は補償されません。
2. **警察届出（110番）の絶対遵守**：
   * 単独転倒や軽微な接触であっても、警察への事故届出がない場合、保険金請求が認められない場合があります。
3. **示談代行サービスなし（本部窓口一本化）**：
   * NPO活動総合保険には損保側の示談代行サービスが付帯しないため、サポーターはその場で示談や口約束を行わず、**必ずKidsRide本部が損保会社と連携して対応**します。
